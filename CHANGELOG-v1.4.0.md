# DSPi ESP32 Front Panel v1.4.0

Released 2026-10-18, based on v1.3.1.

- Add the Outputs menu with named channel controls, routing, EQ and crossover.
- Add precise digit editors, hundredth-dB gains and explicit full-channel parameter copying.
- Add editable stereo-to-mono summing with independently chosen Left and Right gains.
- Add manual speaker/sub groups, Quick Controls, Sub Level, Balance and scoped saved-value restoration.
- Add preset naming, Save As New, New Preset and destination previews.
- Add panel input aliases, menu visibility/order and matching source announcements.
- Expose supported native hardware/input/output/clock settings through guarded menus.
- Include complete graphical and text menu documentation.

See [release notes](RELEASE-NOTES-v1.4.0.md) for usage, compatibility and installation.

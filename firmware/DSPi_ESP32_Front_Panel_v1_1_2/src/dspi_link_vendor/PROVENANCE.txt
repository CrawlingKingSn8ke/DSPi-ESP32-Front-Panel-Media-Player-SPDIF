Portable components only: no app_main, independent UART task, updater,
factory erase, GPIO initializer or standalone server imported.
Files are flattened and normalised to LF with a final newline.

Local patches:
- dspi_link.c: native0x90 SET acknowledgement window650ms.
- hub.h/hub.c: optional reserved_poll_bps (zero preserves upstream
  behaviour); absent-device budget uses configured baud. Panel reserves
  3000B/s for local work. Native commands and Master/User Volume unchanged.
- hub_auth.h/hub_auth.c: optional checked persistence callback; panel PIN,
  pairing and revocation fail without changing live authentication state
  when flash rejects the write. Legacy void-save ports remain compatible.

Browser: pinned js/package-lock.json; npm11.6.2; Vite7.3.6.
local-validation/dspi-link-browser-panel.patch restricts settings to
Status/Security, requires PIN and replaces standalone reset advice.
local-validation/dspi-link-browser-controls.patch and browser-overrides/
volume-writer.ts serialize volume writes, coalesce only unsent values,
cancel pending writes on disposal and clear warnings on successful writes.
Build-Link-Web.ps1 invokes upstream bridge/esp32/tools/embed_web.py:
web_assets_data.c is generated using deterministic gzip(mtime=0).
Panel refuses /setup and /setup.html; network setup is a separate,
physically opened, PIN-authorised panel mode.
